Installation instructionsIf you are starting a new project, please consider using our [Starter
Kit](https://github.com/ReactVision/expo-starter-kit-typescript) as a basis
for your app.
The steps below are for manually installing and linking the library to an
existing React Native project. We do not yet support auto-linking.
##
Install####
NPMconsole
    $ npm install --save @reactvision/react-viro
####
Yarnconsole
    $ yarn add @reactvision/react-viro
